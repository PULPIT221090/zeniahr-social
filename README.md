# zeniahr-social

Public image host and design kit for ZeniaHR's Instagram (@zenia_hr) and LinkedIn posts.

- `assets/YYYY-MM-DD/`: final post images (JPG, 1080×1350), motion posts (MP4 + GIF + cover JPG). Zoho Social pulls these through raw.githubusercontent.com URLs.
- `kit/`: design kit (`kit.py`), build scripts, captions and the post manifest (running ground index k for the navy → mist → copper grid rotation).

Published by the ZeniaHR social agents. Please don't rename or delete files that are already scheduled.
